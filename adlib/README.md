# adlib

AdLib-style FM sound effects, a mixer and music, with no dependencies. Copied from the `coriolis` project at commit `f936374` so that this repo builds on its own. It is under the MIT licence in [LICENSE](LICENSE).

The `coriolis` namespace and include paths are kept, so a newer version can be dropped in by replacing these files. Changes made here do not flow back to `coriolis`.
